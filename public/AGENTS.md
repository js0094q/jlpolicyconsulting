# AGENTS.md

## Scope

Applies to `public/**`.

## Rules

- Store only committed static assets that are served by the website.
- Do not place drafts, source documents, private collateral, or generated work-in-progress here.
- Use descriptive, stable filenames.
- Keep social/brand assets under `public/social/` when they are part of the public site or public profile kit.
- If replacing an asset, verify all references and avoid breaking existing URLs unless the user approves the change.
