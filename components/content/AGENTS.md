# AGENTS.md

## Scope

Applies to MDX editorial components in `components/content/**`.

## Rules

- Components must support comprehension: evidence, implications, comparisons, methods, sequencing, or reader orientation.
- Do not add decorative-only MDX components.
- Keep props typed and simple enough to use directly from MDX.
- Preserve restrained styling and mobile readability.
- Update `components/mdx-components.tsx` when adding a new MDX component.
- Update `docs/specs/mdx-component-inventory.md` for any new or materially changed MDX component.
