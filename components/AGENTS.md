# AGENTS.md

## Scope

Applies to `components/**`, except where a deeper `AGENTS.md` applies.

## Rules

- Prefer existing components before adding new ones.
- Keep components small, typed, and presentation-focused.
- Use existing design tokens and utility classes from `app/globals.css`.
- Avoid generic marketing modules, decorative UI, and broad visual rewrites.
- Keep accessibility basics intact: semantic elements, readable link text, focus-visible states, and no inaccessible icon-only actions.
- If component behavior changes, add or update tests where the behavior is covered.
