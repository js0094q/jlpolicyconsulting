# SPUF Analysis Package

This package converts the SPUF quarter analysis into publication-ready assets for JL Policy Consulting.

## Package contents

- `data/`
  - Structured outputs for five completed analysis streams.
- `workbooks/spuf-analysis-dashboard.xlsx`
  - Executive workbook with charts, analysis tabs, and story pipeline tab.
- `docs/spuf-policy-brief.docx`
- `docs/spuf-policy-brief.pdf`
  - Client-facing brief version of core findings.
- `frontend/spuf-story-concept.html`
  - Presentable narrative concept page.

## Five completed analysis streams

1. Repricing vs churn decomposition by quarter pair.
2. Generic tier worsening with same-NDC controls.
3. Sponsor segmentation into repricing-dominant vs churn-dominant patterns.
4. PBM mail and retail channel profiling.
5. Beneficiary cost-sharing and tier movement linkage.

## Core narrative thesis

Observed data patterns are consistent with a sponsor behavior thesis: low-cost generics appear to move to higher tiers in selected concepts while sponsor activity remains elevated. This is framed as an inference, not a direct proof of margin realization.

## Claim guardrails

- Use `Observed` for measured file-level results.
- Use `Inferred` for strategy interpretation.
- Do not claim direct margin increase as an established causal fact without additional financial evidence.
