# Adrabetadex ARM Training Materials — Client Delivery

Use this package as a client handoff for the Adrabetadex ARM training set.

## Included Items and Intended Use

- `Adrabetadex_01_Fact_Matrix.docx`
  - Master assumptions and policy logic map that defines the ARM model inputs, definitions, and interpretation notes.
  - Intended use: baseline reference for the team before review or implementation discussions.

- `Adrabetadex_02_Billing_Code_Reference.docx`
  - Billing code dictionary and reference tables for provider-facing coding/compliance context.
  - Intended use: quick lookup during implementation planning and payer-side execution alignment.

- `Adrabetadex_03_ARM_Training_Guide.docx`
  - Step-by-step training guide describing workflow, methodology, and how to use the outputs.
  - Intended use: internal and client-facing training packet for pre-read before live model walkthroughs.

- `Adrabetadex_Provider_Net_Cost_Recovery_Calculator.xlsx`
  - Calculation workbook and scenario calculator.
  - Intended use: hands-on modeling in spreadsheet sessions to validate recovery cases and assumptions.

- `Adrabetadex_04_Full_ARM_Training_Deck.pptx`
  - Complete presentation deck for extended workshops and team review sessions.
  - Intended use: primary training presentation for operational rollout and decision support.

- `Adrabetadex_05_Executive_ARM_Overview.pptx`
  - Condensed executive deck focused on business implications and high-level takeaways.
  - Intended use: leadership alignment and sponsor/decision-maker briefings.

- `Adrabetadex_07_ARM_Output_One_Page_Summary.pdf`
  - One-page PDF summary of key model outputs and recommendations.
  - Intended use: quick executive distribution and follow-up reference after meetings.

## Delivery Notes

- All files are included for client use in packaged form under this folder.
- Keep filenames unchanged after this handoff for version tracking and distribution references.
